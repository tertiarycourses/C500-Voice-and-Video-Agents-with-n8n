HarbourStay Voice Concierge

Record one short synthetic question. The page sends audio to your n8n webhook and plays the returned MP3. It never asks for an API key.

Ready. Save a Test URL, start n8n listening, then record a short question.

Microphone access normally requires localhost or HTTPS. Only the webhook URL is stored in this browser.

Use synthetic questions
  • “What time can I check in if I arrive late?”
  • “When is breakfast served?”
  • Handoff check: “Change Alex Tan’s booking.”

multipart/form-data
binary field data
